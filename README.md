Harbour Grand Hotel Website

Project Overview

This is a complete static website for Harbour Grand Hotel, a luxury waterfront hotel. The website showcases the hotel's rooms, facilities, gallery, and provides a seamless booking experience for potential guests. Built with HTML5, CSS3, and JavaScript, it features a responsive design that works across all devices.
